Kebijakan Privasi

Terakhir diperbarui: 8 November 2026

Data yang kami simpan

Data keuangan yang kamu catat (transaksi, wallet, budget, target tabungan, utang, tagihan) disimpan di perangkatmu. Dari akun Google kami hanya memakai nama, email, foto profil, dan ID akun untuk mengidentifikasi akunmu.

Isolasi data

Setiap akun Google memiliki database terpisah di perangkat. Data satu akun tidak dapat dibuka oleh akun lain.

Berbagi data

Monvix tidak menjual atau membagikan data keuanganmu. Berkas backup dan laporan hanya keluar dari perangkat saat kamu sendiri membagikannya atau memilih mencadangkan ke Google Drive.

Backup Google Drive

Bila kamu memilih backup ke Google Drive, berkas disimpan di folder data aplikasi pada Drive milikmu sendiri dan hanya dapat dibuka oleh Monvix. Monvix hanya meminta izin folder data aplikasi (drive.appdata), bukan seluruh isi Drive. Kamu dapat menghapus backup itu kapan saja dari halaman Backup.

Penggunaan data pengguna Google

Penggunaan dan pengalihan informasi yang diterima dari Google API oleh Monvix mematuhi Kebijakan Data Pengguna Layanan Google API, termasuk persyaratan Penggunaan Terbatas. Data dari Google hanya dipakai untuk menyediakan fitur masuk dan backup, tidak dipakai untuk iklan, dan tidak dijual.

Keamanan

Token masuk disimpan di penyimpanan aman perangkat. PIN disimpan dalam bentuk hash. Kamu dapat mengunci aplikasi dengan PIN atau biometrik.

Menghapus data

Menu Hapus Akun menghapus data lokal, cadangan lokal, sesi, dan pengaturan akun tersebut dari perangkat. Backup di Google Drive tidak ikut terhapus; hapus lewat halaman Backup sebelum menghapus akun.
